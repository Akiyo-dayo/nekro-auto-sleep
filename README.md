# NekroAgent 自动睡眠插件

为每个会话提供独立的拟人化睡眠周期，无需修改 NekroAgent 核心代码。

## 功能

- **定时入睡与随机起床**：默认每晚 23:00 静默入睡，次日 06:45–08:30 之间随机自然醒
- **两次叫醒协议**：睡眠中用户有效呼叫→固定提示（不经 LLM）→同一用户再次呼叫→正常唤醒进 LLM
- **静默拦截**：睡眠期间随机回复、主动回复、普通系统消息被完全拦截，不触发 LLM
- **定时任务兼容**：定时任务可临时唤醒执行，完成后自动恢复睡眠
- **主动睡下**：Bot 可调用 `resume_sleep` 工具重新入睡
- **空闲自动睡回**：被叫醒后无新互动自动静默睡回（默认 10 分钟）
- **睡眠质量统计**：基于连续积分模型计算质量百分比（非固定扣分）
- **自然醒通知**：满足条件时发送角色扮演式起床报告
- **双版本兼容**：同时兼容 Akiyo 版与原版上游 NekroAgent

## 安装

将 `nekro_auto_sleep/` 目录复制到 NekroAgent 的 `plugins/external/` 下：

```
plugins/external/nekro_auto_sleep/
├── __init__.py
├── models.py
├── schedule.py
├── quality.py
├── engine.py
├── persistence.py
├── runtime.py
└── tests/
```

重启 NekroAgent 后在插件管理页面启用「自动睡眠」插件。

## 配置

所有配置项均支持 WebUI 中文界面，在插件设置页面可直接修改：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用自动睡眠 | `true` | 总开关 |
| 时区 | `Asia/Shanghai` | IANA 时区名称 |
| 入睡时间 | `23:00` | 每日自动入睡时间（HH:MM） |
| 起床时间范围（起始） | `06:45` | 随机起床最早时刻 |
| 起床时间范围（结束） | `08:30` | 随机起床最晚时刻 |
| 起床随机粒度 | `1` 分钟 | 候选起床点间隔 |
| 接近起床判定比例 | `0.15` | 末段比例，提示语切换为「还没起床」 |
| 叫醒确认窗口 | `180` 秒 | 二次叫醒的时间窗口 |
| 历史记录模式 | `preserve` | `preserve`=保留消息 / `strict`=完全拦截 |
| 呼叫关键词 | `醒醒,起床,在吗` | 触发叫醒的关键词（逗号分隔） |
| 默认人格名 | `Bot` | 获取预设名失败时的回退名 |
| 提前叫醒空闲超时 | `10` 分钟 | 被叫醒后无互动的睡回时间 |
| 离线补发宽限期 | `120` 分钟 | 重启后补发自然醒通知的最大延迟 |
| 维护循环间隔 | `15` 秒 | 后台检查间隔 |
| 定时任务等待超时 | `900` 秒 | 插件等待定时任务完成的上限 |
| 睡眠质量下限 | `60` | 质量百分比最低值 |
| 睡眠质量上限 | `120` | 质量百分比最高值 |
| 质量稳定扰动幅度 | `4.0` | 每次质量的随机扰动范围 |

## 工作流程

### 正常睡眠

```
23:00 → Bot 静默入睡（不发消息）
       ↓ 睡眠期间：群聊普通消息静默拦截
       ↓ 随机/主动回复完全静默
06:45-08:30 → 随机时间自然醒
       ↓ 如有人叫过但未叫醒 → 发送起床报告
       ↓ 无人叫过 → 静默起床
```

### 叫醒流程

```
用户有效呼叫 → 【Bot已经睡了 要叫醒Bot吗？】(不经 LLM)
       ↓ 同用户 3 分钟内再次呼叫
       → 切换为 AWAKE_EARLY，本轮正常进 LLM
       → 注入"你刚刚被用户提前叫醒了"（不写历史）
       ↓ 10 分钟无新互动 → 静默睡回
       ↓ 或 Bot 调用 resume_sleep → 【Bot已睡下】
```

### 接近起床

```
用户呼叫 → 【Bot还没起床 要叫醒Bot吗？】
       ↓ 后续流程同上
```

## 状态机

```
AWAKE ──(到达入睡点)──→ ASLEEP
                          │
              ┌───────────┤
              │           │
         (二次叫醒)   (计划起床)
              │           │
              ▼           ▼
        AWAKE_EARLY ──→ AWAKE
              │
     (空闲/resume_sleep)
              │
              ▼
           ASLEEP
```

## 兼容性

- Akiyo 版 NekroAgent (`Akiyo-dayo/NekroAgent_ByAkiyo`)
- 原版上游 NekroAgent (`KroMiose/nekro-agent`)

通过运行时 `getattr` 能力探测实现兼容，不按版本号分支。

## 技术要点

- 不修改任何 NekroAgent 核心文件
- 使用 `DBPluginData` / `PluginStore` 持久化，不建表
- 每个 `chat_key` 独立状态、独立异步锁
- Pydantic 严格验证，schema 版本保护
- 领域层（models/schedule/engine/quality）不导入宿主单例，可独立测试
- 包装函数带私有标记，防重复安装，cleanup 时安全恢复

## 许可

与 NekroAgent 保持一致。
